# 우주펭귄상회 글쓰기 작업실

적용 버전: `spacepenguin-editorial-v2-20261116`

## 사용할 때

스튜디오 원고의 **이야기** 단계, 릴스 편집 화면, 기존 카드뉴스와 8장 카드뉴스 편집기의 **글쓰기 작업실**을 펼칩니다. 작업을 고르고 주제·독자·확인한 자료·수정 지시를 입력합니다. 현재 편집 중인 원고를 참고하며, 기획 메모는 직접 체크한 경우에만 포함합니다.

**스튜디오에서 제안 받기**는 선택한 AI API에 명시적으로 요청합니다. 결과에서 도입 후보·추천 이유·구성·최종 문구를 검토하고 복사하거나 허용된 편집 필드에 직접 반영합니다. 콘텐츠 저장은 별도입니다. 8장 편집기에서는 장별 구조를 보존하도록 복사만 제공합니다. 연결된 AI가 없으면 **ChatGPT에서 같은 기준으로 작성하기**에서 요청을 복사할 수 있습니다.

작업은 릴스 대본, 캡션 점검, 카드뉴스 기획, 프로필 점검, 스토리 순서, 주간 계획, 내 말투로 다듬기, 댓글 초안, 답글 정리, DM 답장, 콘텐츠 재구성, 뜨는 소재 조사, 지난 게시물 점검으로 나뉩니다. 댓글·답글·DM 결과는 초안이며 전송 기능은 없습니다. 최신 소재 조사의 앱 내 AI 실행에는 검색 도구가 연결되지 않으므로 제공 자료 분석과 검색 계획을 작성하고, 새 자료가 없으면 조사 대기라고 표시합니다.

## 글쓰기 기준

- 구체적인 사건·장면·대상·행동부터 시작합니다. 표지에서 약속한 내용은 첫 내지에서 보여줍니다.
- 생활 속 비유와 반전은 살리면서 실제 주체·대상·시제·조건을 확인합니다. 기존에 채택한 제목도 사실 표현의 정답으로 고정하지 않습니다.
- 모호한 분야명은 실제 활동·제출물·관심 분야로 풀어 씁니다. 확인할 수 없는 핵심 조건을 독자에게 떠넘기거나 임의로 완성하지 않습니다.
- 사건에서 이유와 생활의 의미로 이어갑니다. 모든 뉴스를 육아·영재교육·훈계로 끝내지 않습니다.
- 좋은 기존 문장과 잠금 문구를 보존합니다. 도입 후보를 요청할 때는 같은 문장의 변형 대신 서로 다른 각도 3개를 제안합니다.
- 사실 추출 전용 단계와 이미지 지시에는 문체 규칙을 섞지 않습니다. 기존 JSON 구조와 카드 장수는 유지합니다.

이 기준은 일반 스튜디오 원고·캡션·한 컷 수정, 모집 카드 문구, 8장 뉴스, 가족 대화 기획·원고·캡션·부분 수정·검수, 사진 후기, 완성 카드의 캡션, ChatGPT 수동 요청에 공통으로 연결됩니다. 채널별 지침과 명시적인 사용자 수정 범위가 우선합니다.

## 데이터와 실행

- 작업실 입력은 기존 계정별 기기 복구 기능을 사용합니다. 복구해도 기획 메모 포함은 다시 선택합니다.
- 생성 결과는 현재 원고를 자동으로 덮어쓰지 않습니다. 요청 이후 원고·입력이 달라지면 예전 결과의 반영 버튼을 막습니다.
- 서버는 저장된 카드의 실제 채널·버전·채널 AI 설정을 사용합니다. 같은 요청 ID의 동일 결과를 다시 확인할 수 있으며, 입력을 바꿔 같은 ID를 재사용할 수 없습니다.
- 같은 카드의 기존 생성과 새 글쓰기 요청은 동시에 실행하지 않습니다. 취소·휴지통·전체 정지·버전 변경을 검사하며, 처리 결과가 불명확한 요청을 자동 재생성하지 않습니다.
- 작업 메타데이터와 감사 로그에는 입력 원문 대신 요청 해시·작업 종류·모델·버전을 기록합니다. 생성 결과는 인증된 작업 결과로 보관합니다.
- 로컬 편집 점검은 문장 형태를 살피는 도구입니다. 사실의 진위, 조회수, 확산 가능성, 인스타그램 알고리즘 점수를 판정하지 않습니다. 캡션 125자는 편집용 미리보기입니다.
- 성과 점검은 광고 여부·형식·게시 후 시간·영상 길이·분모를 구분합니다. 조회수와 고유 시청자, 3초 유지율과 평균 시청 비율·끝부분 유지율을 혼동하지 않습니다.

## 검증

`tests/sns-editorial*.test.ts`, `tests/sns-writing-workbench-ui.test.tsx`, `tests/sns-editorial-generation-ui.test.tsx`에서 실제 생성 프롬프트, API·PostgreSQL의 버전/중복/취소 처리, 미저장 원고 연결, 기기 복구, 이전 제안의 반영 차단을 검사합니다. 외부 AI는 모의 응답입니다.

빌드 후 `node scripts/sns-writing-regression.mjs`는 실제 React 화면을 1440px·390px에서 열고 13개 작업, 제안 결과, 최신 영상 대본, 가로 넘침과 이전 제안 반영 차단을 확인합니다. HTTP API는 합성 자료로 대체하며 외부 요청·실제 게시·유료 생성을 하지 않습니다. 캡처와 결과는 `test-results/sns-writing/`에 저장합니다.

GitHub 조사 범위·별 수·원자료·채택한 구조는 [SNS_AUTOMATION_REFERENCES.md](SNS_AUTOMATION_REFERENCES.md)에 기록했습니다.
