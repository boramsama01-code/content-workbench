# 우주펭귄상회 글쓰기 작업실

적용 버전: `spacepenguin-editorial-v2-20261116`

## 사용할 때

스튜디오 원고의 **이야기** 단계, 릴스 편집 화면, 기존 카드뉴스와 8장 카드뉴스 편집기의 **글쓰기 작업실**을 펼칩니다. 작업을 고르고 주제·독자·확인한 자료·수정 지시를 입력합니다. 현재 편집 중인 원고를 참고하며, 기획 메모는 직접 체크한 경우에만 포함합니다.

작성 연결에서 **이 PC의 Codex** 또는 **AI API**를 고릅니다. Codex는 이 PC에 로그인한 ChatGPT 연결과 사용 한도로 실행하며 PC가 켜져 있어야 합니다. API는 채널에 설정한 별도 API 연결을 사용합니다. 연결된 Codex가 있으면 처음 펼칠 때 Codex를 기본으로 선택합니다.

결과에서 도입 후보·추천 이유·구성·최종 문구를 검토하고 복사하거나 허용된 편집 필드에 직접 반영합니다. 콘텐츠 저장은 별도입니다. 8장 편집기에서는 장별 구조를 보존하도록 복사만 제공합니다. 연결을 사용할 수 없으면 **ChatGPT에서 같은 기준으로 작성하기**에서 요청을 복사할 수 있습니다.

결과의 **이 안에서 바꿀 점**에 피드백을 적고 **이 제안에서 이어 다듬기**를 누르면 현재 원고를 덮어쓰지 않고 직전 제안을 다시 다듬습니다. 도입 후보를 선택해 그 표현을 유지하도록 요청할 수도 있습니다. 최초 근거·원고와 직전 제안만 전달하며, AI의 이전 문장을 사실의 근거로 사용하지 않습니다. 재수정은 버튼을 누를 때 새 작성 작업을 명시적으로 시작합니다. 처리 여부가 불명확한 요청을 다시 확인할 때는 같은 ID·본문을 사용합니다.

Codex 작업은 고정 모델 `gpt-6.1-sol`, 추론 `ultra`로 초안을 쓰고 별도 요청의 편집자가 자료 일치·조건·말투·흐름·수정 범위를 검토합니다. 필요하면 한 번 고쳐 다시 검토하며 한 작업은 최대 네 번의 모델 실행으로 제한됩니다. 자료가 부족하면 사실을 만들어 수정하지 않습니다. 다섯 항목을 통과하지 못한 제안은 복사·재수정만 제공하고 원고 반영을 막습니다. 이는 제공 자료와의 대조이지 외부 검색을 통한 사실 검증이나 성과 보증이 아닙니다. 현재 채팅의 전체 맥락이 자동 공유되지는 않습니다.

**다음 글에도 기억할 기준**에서 수정 규칙과 채택한 표현·수정 이유를 직접 저장합니다. 자동 학습하지 않으며 저장·삭제할 때만 채널별 기억을 바꿉니다. 사례는 말투 참고이고 새 글의 사실 자료와 분리됩니다. 요청마다 당시 기억의 버전과 해시를 고정합니다.

## Canva에서 편집하고 돌아올 때

콘텐츠의 **Canva 저장 연동**에서 해당 콘텐츠용 디자인을 연결하고 **저장 내용 자동 반영**을 켭니다. **Canva에서 편집**으로 이동해 저장하면 Studio에서 변경을 감지해 PNG 이미지와 같은 저장 버전의 PDF 문구를 새 버전으로 가져옵니다. 1~20장을 지원하며 기존 원고·이미지는 이전 버전에 남깁니다. 공용 템플릿 원본과 다른 콘텐츠에 연결된 디자인은 연결할 수 없습니다.

Canva는 디자인 저장 웹훅을 제공하지 않아 화면 복귀와 15초 간격 확인을 사용합니다. 내보내기가 진행 중이면 다음 확인에서 이어 받으므로 저장 즉시 같은 시각에 반영되지는 않습니다. 화면을 닫은 뒤에는 이 PC의 연결 작업기가 켜져 있을 때만 확인을 이어갑니다.

Studio에서도 수정한 경우 자동으로 덮어쓰지 않고 충돌을 표시합니다. 편집 중 새 결과가 도착해도 현재 입력과 편집기 종류를 유지합니다. 실제 Canva 문구는 기존 구조화된 장별 입력 칸과 자동 대응됐다고 가정하지 않고 별도로 대조할 수 있게 보관합니다. PDF에 텍스트가 없거나 일부만 읽히면 확인 필요로 표시하며 이전 원고를 현재 Canva 문구라고 취급하지 않습니다. 발행 승인은 새 결과를 기준으로 다시 받아야 합니다.

## 이 PC의 연결 작업기 설치

`npm run build`에 로컬 작업기 빌드가 포함됩니다. Windows에서 `scripts/install-codex-writer.ps1`에 설치된 Node 22 실행 경로를 전달합니다. Codex 로그인은 기존 공식 CLI가 직접 사용하며 인증 파일을 읽거나 내보내지 않습니다. Studio 전용 연결 키는 현재 Windows 사용자용 DPAPI로 보호하고 서버에는 SHA-256 지문만 설정합니다. `-Autostart -Start`는 현재 사용자의 시작프로그램으로 숨겨진 작업기를 실행합니다. 전원 설정·보안 정책은 바꾸지 않습니다.

작업기는 서버에서 명시적으로 접수한 글쓰기 요청과 이미 켜 둔 Canva 연결만 처리합니다. Codex는 비어 있는 임시 폴더에서 읽기 전용으로 실행하며 셸·앱·웹 검색 등 작업 도구를 사용하지 않습니다. 임시 출력은 종료 후 지우며 원문·추론·비밀값 로그를 남기지 않습니다. 연결이 끊겨 처리 여부를 알 수 없는 작업은 자동으로 모델을 다시 실행하지 않습니다.

작업은 릴스 대본, 캡션 점검, 카드뉴스 기획, 프로필 점검, 스토리 순서, 주간 계획, 내 말투로 다듬기, 댓글 초안, 답글 정리, DM 답장, 콘텐츠 재구성, 뜨는 소재 조사, 지난 게시물 점검으로 나뉩니다. 댓글·답글·DM 결과는 초안이며 전송 기능은 없습니다. 최신 소재 조사의 앱 내 AI 실행에는 검색 도구가 연결되지 않으므로 제공 자료 분석과 검색 계획을 작성하고, 새 자료가 없으면 조사 대기라고 표시합니다.

## 글쓰기 기준

- 구체적인 사건·장면·대상·행동부터 시작합니다. 표지에서 약속한 내용은 첫 내지에서 보여줍니다.
- 생활 속 비유와 반전은 살리면서 실제 주체·대상·시제·조건을 확인합니다. 기존에 채택한 제목도 사실 표현의 정답으로 고정하지 않습니다.
- 모호한 분야명은 실제 활동·제출물·관심 분야로 풀어 씁니다. 확인할 수 없는 핵심 조건을 독자에게 떠넘기거나 임의로 완성하지 않습니다.
- 사건에서 이유와 생활의 의미로 이어갑니다. 모든 뉴스를 육아·영재교육·훈계로 끝내지 않습니다.
- 좋은 기존 문장과 잠금 문구를 보존합니다. 도입 후보를 요청할 때는 같은 문장의 변형 대신 서로 다른 각도 3개를 제안합니다.
- 모집은 조건과 준비 행동, 경험은 막힘·해결·재수정 과정, 뉴스는 장면과 이유를 중심으로 씁니다. 경험담의 작은 농담과 자연스러운 말걸기는 살리되, 설명을 줄이느라 독자가 필요한 단계를 추측하게 만들지 않습니다.
- 사실 추출 전용 단계와 이미지 지시에는 문체 규칙을 섞지 않습니다. 기존 JSON 구조와 카드 장수는 유지합니다.

이 기준은 일반 스튜디오 원고·캡션·한 컷 수정, 모집 카드 문구, 8장 뉴스, 가족 대화 기획·원고·캡션·부분 수정·검수, 사진 후기, 완성 카드의 캡션, ChatGPT 수동 요청에 공통으로 연결됩니다. 채널별 지침과 명시적인 사용자 수정 범위가 우선합니다.

이 설정은 실제 제작 대화와 최종본에서 도출한 편집 규칙입니다. 모델을 재학습한 것이 아니며, 기능 검증이나 AI 자체 검토만으로 사용자의 최종본과 같은 완성도를 보장하지 않습니다. 실제 채택 결과와의 비교는 계속 필요합니다.

## 데이터와 실행

- 작업실 입력은 기존 계정별 기기 복구 기능을 사용합니다. 복구해도 기획 메모 포함은 다시 선택합니다.
- 생성 결과는 현재 원고를 자동으로 덮어쓰지 않습니다. 요청 이후 원고·입력이 달라지면 예전 결과의 반영 버튼을 막습니다.
- 서버는 저장된 카드의 실제 채널·버전·채널 AI 설정을 사용합니다. 같은 요청 ID의 동일 결과를 다시 확인할 수 있으며, 입력을 바꿔 같은 ID를 재사용할 수 없습니다.
- 같은 카드의 기존 생성과 새 글쓰기 요청은 동시에 실행하지 않습니다. 취소·휴지통·전체 정지·버전 변경을 검사하며, 처리 결과가 불명확한 요청을 자동 재생성하지 않습니다.
- 작업 메타데이터와 감사 로그에는 입력 원문 대신 요청 해시·작업 종류·모델·버전을 기록합니다. 생성 결과는 인증된 작업 결과로 보관합니다.
- 로컬 편집 점검은 문장 형태를 살피는 도구입니다. 사실의 진위, 조회수, 확산 가능성, 인스타그램 알고리즘 점수를 판정하지 않습니다. 캡션 125자는 편집용 미리보기입니다.
- 성과 점검은 광고 여부·형식·게시 후 시간·영상 길이·분모를 구분합니다. 조회수와 고유 시청자, 3초 유지율과 평균 시청 비율·끝부분 유지율을 혼동하지 않습니다.

## 검증

`tests/sns-editorial*.test.ts`, `tests/sns-writing-workbench-ui.test.tsx`, `tests/sns-editorial-generation-ui.test.tsx`에서 실제 생성 프롬프트, API·PostgreSQL의 버전/중복/취소 처리, 미저장 원고 연결, 기기 복구, 이전 제안의 반영 차단을 검사합니다. 외부 AI는 모의 응답입니다.

2026-11-16에는 별도의 로컬 작업기와 실제 로그인된 Codex(`gpt-6.1-sol`, `ultra`)를 사용해 세 가지 작성 작업을 접수부터 완료까지 실행했습니다. 경험담 5장, 가상 모집 조건 안내 4장, 고정 제목·문장을 보존하는 부분 수정이 모두 완료됐으며 각각 별도 편집 검토의 다섯 항목을 통과했습니다. 원고를 자동 저장하지 않았고 확정 제목·문장 보존도 확인했습니다. 모집 조건은 실제 공고가 아닌 검증용 가상 자료로 표시했습니다. 이 사례들은 실제 연결·자료 일치·범위 보존의 실행 증거이며 계정 성과나 모든 주제의 문체 재현율을 보여주는 통계는 아닙니다. 실제 사용자 Canva 저장 후 가져오기 확인은 운영자 로그인 뒤 별도로 진행해야 합니다.

빌드 후 `node scripts/sns-writing-regression.mjs`는 실제 React 화면을 1440px·390px에서 열고 13개 작업, 제안 결과, 최신 영상 대본, 가로 넘침과 이전 제안 반영 차단을 확인합니다. HTTP API는 합성 자료로 대체하며 외부 요청·실제 게시·유료 생성을 하지 않습니다. 캡처와 결과는 `test-results/sns-writing/`에 저장합니다.
